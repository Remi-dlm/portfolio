# Portfolio Rémi Dalmasso

Site statique HTML/CSS/JS bilingue, inspiré de la structure des fichiers de référence transmis.

## Utilisation
Ouvrir `index.html` dans Chrome. Naviguer avec le menu et changer de langue avec FR/EN. Les filtres de projets fonctionnent.

## Avant publication
- Ajouter les photos et graphiques réels dans `assets/images/` et remplacer les illustrations provisoires.
- Ajouter une adresse e-mail, un lien LinkedIn et le CV après validation.
- Relire les descriptions techniques et vérifier la confidentialité des contenus CINEA.
- Héberger le dossier sur GitHub Pages ou Netlify, puis placer le lien sur le CV.

Les pages du portfolio de référence n'ont pas été copiées telles quelles : le contenu a été adapté.

Fiches visuelles actualisées : projets/loup.html, projets/mq19.html, projets/cinea.html, projets/jardin.html. Les rapports PDF sont disponibles dans assets/documents. Images issues des pages des rapports, à recadrer davantage si nécessaire.

Photo externe de violoncelle sur les cartes « Note du loup » : Metropolitan Museum of Art, via Wikimedia Commons, fichier « Violoncello MET DT7705.jpg », licence CC0. Le navigateur doit avoir accès à Internet pour afficher cette photo. Image de repli locale si indisponible.
